# Premium Digital Business Card - Khalid Aanaoui

A modern, luxury, premium digital business card website built using pure **HTML, CSS (via Tailwind CSS CDN v3), and Vanilla JavaScript**.

This project is 100% static, requires no compilation or build steps, and works immediately upon opening `index.html` or hosting on **GitHub Pages**.

## ✨ Features

- 🌟 **Bilingual Support**: Instant toggle between high-contrast English (Poppins) and Arabic (Cairo) typography with perfect right-to-left (RTL) formatting.
- 🎨 **Luxury Glassmorphism**: High-end translucent elements, floating background gradient orbs, and professional golden `#D4AF37` highlights.
- 📱 **Tactile Interactions**: Fully responsive touch-optimized buttons, micro-vibration scales, and customized ripple hover effects.
- 📂 **Direct VCF Download**: One-tap "Save Contact" button instantly downloads a pre-formatted VCF card with Khalid's details.
- 🔗 **QR Code & Native Sharing**: Dynamic QR code modal for swift physical-to-digital connections and native mobile sharing.
- 🌗 **Dark / Light Modes**: Eye-safe luxury dark background with smooth transitions to a high-contrast elegant light mode.

## 📁 Files Included

- `index.html` — The main structural page containing the custom vector emblem and bilingual layouts.
- `style.css` — Custom keyframe animations, glowing background orbs, glassmorphic styling, and RTL adjustments.
- `script.js` — Core state logic, translations, ripple actions, dynamic QR generation, and touch triggers.
- `manifest.json` — Progressive Web App (PWA) manifest for adding to home screens.
- `contact.vcf` — Virtual Contact File for effortless contacts backup.
- `logo.png` — High-resolution digital identity icon.

## 🚀 How to Host on GitHub Pages

1. Create a new repository named `Business` on GitHub.
2. Upload the project files directly.
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment**, set the source to **Deploy from a branch**.
5. Select the `main` branch and click **Save**.
6. Your luxury digital card will be live at: `https://<your-username>.github.io/Business/`
